# Key steps taken from the literature

Steps extracted from the papers of the RQ1 bibliography (`bibliography.2026-11-11a.bib`); each was re-checked independently by a sceptic agent against primary sources and code repositories.
**Verdict**: fact-check of "what they did" (partially confirmed = the text was corrected; unverified = no independent support found). **Ours** = the adaptation goes beyond what the source prescribes, so it is our design, not the paper's claim. **Here** = state in this tool. Evidence, quotes and repository paths: `docs/research/` (one report per group and its verification report).

Summary: 99 steps; 33 implemented, 30 partly, 36 planned.
